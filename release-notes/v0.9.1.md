# GRAIL'D 0.9.1

- Fixed Discord sign-in certificate errors on macOS by explicitly using the bundled trusted CA certificates. Certificate and hostname verification remain enabled on every platform.

- Added signed Mac automatic update checks, downloads and Restart & Install for Apple Silicon and Intel. The installer keeps a verified backup and restores the previous app if startup fails. Existing manual-only Mac builds need this build installed once.

- Added the crowned purple-wave G logo to the app header, Windows executable/window/taskbar icon, and macOS app icon.

- The verified owner can create custom tags with names and hover descriptions, then assign/remove them by Discord ID, from registered players, or directly on the global leaderboard. Custom tags follow the verified account across devices.

- Hover over Game in the top bar to choose Classic Snippets or Random Drop. The menu also supports click and keyboard controls. Changing modes discards the previous round and replaces its save.

- Restored the Game tab in the top navigation. Return to a round after switching tabs without restarting it.
- Current rounds save per account and resume after reopening the app, including song, difficulty, attempts, and the same Random Drop snippet starting point.

- Faster startup: the Windows launcher loads legacy interface libraries only when needed. Music scanning reuses directory metadata and skips MIME lookups for known audio formats.
- Global account tags: tags follow your verified Discord or Google sign-in across installations and appear on the global leaderboard. Use the same provider account on each device.
- Only the verified Discord owner can assign or remove Beta Tester. Owner recognition no longer depends on being the first account on a computer.
- Assign/remove Beta Tester from Account → Profile by pasting a Discord user ID or mention, including before the player's first sign-in. The owner can also assign/remove it directly from global leaderboard entries.
- Top earner: unlock all 50 achievements to earn this permanent profile tag. Existing achievements count.
- Hover over a profile tag, or focus a new tag with the keyboard, to see how it was obtained.
- Last synced tags remain visible offline. Existing achievements count toward Top earner; local gameplay progress, settings, and music folders are preserved.

Windows uses the existing signed beta update channel. macOS builds use separate signed manifests for Intel and Apple Silicon. Mac distribution signing, notarization, and interactive runtime testing remain separate from compilation.
